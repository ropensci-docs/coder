# Classcodes for infection and dislocation after hip arthroplasty

Classcodes for infection and dislocation after hip arthroplasty

## Usage

``` r
hip_ae_hailer
```

## Format

Data frame with 3 columns:

- group:

  Infection or dislocation

- icd10:

  regular expressions based on ICD-10

- kva:

  regular expressions based on NOMESCO/KVA codes
