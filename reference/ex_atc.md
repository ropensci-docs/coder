# Example data for random ATC codes

Example data for fictive people to use for testing and in examples.

## Usage

``` r
ex_atc
```

## Format

Data frames with 100 rows and 2 variables:

- name:

  random person names

- atc:

  Random codes from the Anatomic Therapeutic Chemical classification
  (ATC) system.

- prescription:

  random dates of prescription of medications with corresponding ATC
  codes
